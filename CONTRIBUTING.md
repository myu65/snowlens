# Contributing

Start with an issue describing the user problem and acceptance criteria. Use a
branch, small commits and a pull request. Run lint, typecheck, unit tests, build
and both E2E journeys before merge. Include UI evidence for visible changes.

Keep the table central. Raw sources must work without a Dataset. Do not accept
SQL from the browser or use owner credentials for browsing user data. Add tests
for compiler and authorization changes. Do not commit credentials or real data.
